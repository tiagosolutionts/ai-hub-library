# Replica Skill

**Autor original:** Jake Schincariol  
**Fonte oficial:** https://github.com/Jakeschincariol/replica-skill

Pacote de 11 skills para mapear, planejar, construir, testar e lançar uma implementação independente de funcionalidades de aplicativos.

**Instalação no Claude Code:**

```text
/plugin marketplace add Jakeschincariol/replica-skill
/plugin install replica-skill@replica-skill
```

Esta pasta contém apenas referência e documentação; **não** é um clone do código do projeto original.
