# AI Hub Library

Biblioteca pública de recursos aprovados da [Comunidade IA](https://comunidade-ia.lovable.app).

Este repositório distribui **somente** skills, scripts, prompts e pacotes ZIP com autorização de redistribuição verificada. O código-fonte do portal e a coleção Manus ainda em revisão permanecem privados.

## Estrutura

- [`skills/`](skills/) — referências e skills autorizadas
- [`scripts/`](scripts/) — scripts autorizados
- [`prompts/`](prompts/) — prompts autorizados
- [`downloads/`](downloads/) — ZIPs aprovados
- [`releases/`](releases/) — histórico e notas de versões
- [`LICENSES.md`](LICENSES.md) — licenças e atribuições
